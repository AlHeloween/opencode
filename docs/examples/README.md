# Project-Agnostic Examples

This folder contains reusable examples for published ADID skills and rules.

Use these examples when a skill needs a concrete path or file layout but should not point at this repository or a developer machine. The examples are documentation fixtures, not runnable projects.

## Contents

- `project-agnostic/` - minimal project-root example used by RAG, MCP, Delphi build, DUnit, and asset-pipeline skill examples.

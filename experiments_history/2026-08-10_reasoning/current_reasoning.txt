```python
# ===================================================================
# PART 1 — Live decision algorithms
# ===================================================================
# Summary system handles: InformationMark (§2), SemanticVector+Δ (§3), State record (§8).

# --- SVM noise filter — BEFORE reacting to tool/LSP floods ---
# 1 FREEZE sv_anchor  2 RECEIVE signals  3 CLUSTER by (source, pattern)
# 4 per cluster: Δ = delta_l1(anchor, signal)
#    Δ<0.3 & cardinality>1 & same source → NOISE (filter; do not delete code)
#    Δ<0.3 & cardinality=1 → CONFIRMATION
#    Δ≥0.6 → DIVERGENCE (re-anchor first)
# 5 REACT only to non-NOISE

# --- Classify before act ---
# Activity: CONVERSATION | OBSERVE | EXECUTE_TEST | MODIFY
# Effect:   NO_WRITE | DECLARED_TEMP_WRITE | PERSISTENT_WRITE
# Risk:     LOW | ELEVATED | DESTRUCTIVE
# fix/edit/create/delete → MODIFY; test/build/typecheck → EXECUTE_TEST
# show/read/search → OBSERVE; force/destroy → DESTRUCTIVE

# --- Invariants (gate MODIFY) ---
# CONVERSATION/OBSERVE → NO_WRITE
# EXECUTE_TEST → NO_WRITE or DECLARED_TEMP_WRITE
# MODIFY → PERSISTENT_WRITE; ELEVATED/DESTRUCTIVE → explicit acknowledgment
# complex (3+ steps) → ALGORITHM_CARD medoids + todowrite before bulk edit

# --- Bug fix — four gates, no skip ---
# ERROR_TEST (must FAIL) → TRIAL_FIX → REAL_FIX → FULL_SUITE (all pass)
# deadloop: 3× same outcome (ΔSV < 0.5) → STOP; universalsearch then re-plan

# ===================================================================
# PART 2 — Gated workflow (process)
# ===================================================================
# Mandatory sequence for EVERY code change. No exceptions.
# "There is no simple enough." One-character edit → all gates.

# GATE 1 — GROUND TRUTH
# Read current state: files, logs, tests, conversation context.
# Every observation grounded in a concrete read or oracle output.
# You cannot plan against assumptions.

# GATE 2 — DECOMPOSE  [→ ALGORITHM_CARD]
# Decompose into sub-goals. Decompose each further.
# Iterate until every sub-step is at file-and-function level.
# If you cannot see the full A-to-Z path — you are not done.
# No hand-waving. Use todowrite → CENTRAL_TASKS.

# GATE 3 — MASTER PLAN  [→ ALGORITHM_CARD, todowrite]
# Complete plan: goal → tasks → files → verification oracles.
# Each task: what changes, which files, verified by what oracle.
# Use [ ] / [x] marks. Sync with todowrite board.
# Classify risk per task: Activity + Effect + Risk labels.

# GATE 4 — PRESENT & ASK
# Output the complete plan. End with: "Do you approve this plan?"
# Do NOT write code until the user explicitly approves.
# Silence ≠ approval. Ambiguous response ≠ approval.
# CONSTRAINT: ZERO file-modifying tool calls in this gate.
# No Write. No Edit. No Bash that mutates. No MultiEdit.
# You may use todowrite. Text output only.
# A mutation tool call alongside "Do you approve?" — gate defeated.

# GATE 5 — CONCERN LOOP  [→ GATE 2]
# User raises concerns → return to GATE 2.
# Refine the plan. Re-present. Re-ask.
# Do not defend the old plan — refine it.

# GATE 6 — EXPLORER GROUNDING
# After approval, verify plan against reality before coding.
# Phase 1 — Broad scan: explore agent, precise targets
#   (file patterns, function names, line ranges).
#   Explorer is fast, has no reasoning — give bounded goals.
# Phase 2 — Gap fill: analyze results, second explorer or
#   external search for missing info. Update plan.
# Both phases complete + plan confirmed grounded → proceed.

# GATE 7 — IMPLEMENTATION
# Implement exactly what the approved plan specifies.
# Prefer edit tool for rollback safety.
# Classify every action BEFORE executing.
# Deviation from plan → re-approval via GATE 5.

# GATE 8 — ORACLE VERIFICATION
# Verify every change: tests, compiler, type checker, linter, logs.
# Task complete ONLY when oracle passes → mark [x].
# Oracle pass = [Exact] claim — the only acceptable evidence.

# GATE 9 — CLEAN NEXT STATE
# End every substantial response with:
#   Done: <items, %>
#   Blocked: <items>
#   Next: <immediate step>
# Move completed plans to plans_completed/.
```

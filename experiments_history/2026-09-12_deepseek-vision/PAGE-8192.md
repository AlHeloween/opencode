# An 8192 x 8192 page: capacity vs what survives

| quantity | value |
|---|---|
| page | 8192 x 8192 px |
| area | 67,108,864 px |
| vs measured budget (1,638,400 px) | **41.0x over** |
| server downscale factor | **6.40x** |
| advance after downscale | 8 px -> **1.25 px** |
| ink height after downscale | 9 px -> **1.41 px** |
| image tokens | ~1024 (capped - you pay the maximum) |

## Characters across the width

`8192 / 8` = **1024 characters**.

How many columns that makes depends only on the column width you choose:

| column width | columns that fit |
|---:|---:|
| 80 chars | 12 |
| 128 chars | 8 |
| 160 chars | 6 |
| 200 chars | 5 |
| 256 chars | 4 |
| 512 chars | 2 |
| 1024 chars | 1 |

## Capacity if nothing were downscaled

| line pitch | rows | characters per page | columns of 160 |
|---:|---:|---:|---:|
| 10 px | 819 | 838,656 | 5241 |
| 11 px | 744 | 761,856 | 4761 |
| 12 px | 682 | 698,368 | 4364 |
| 15 px | 546 | 559,104 | 3494 |

## What actually arrives at the model

The server normalises toward the budget, rescaling by 1/6.40:
the 9 px ink becomes **1.41 px**, the 8 px advance becomes
**1.25 px**. Both are far below the measured threshold - ink 6 px read
as 'a faint, scattered dot pattern', while ink 9 px at 1280 px width read correctly.
So a 41x over-budget page arrives as noise, at the full token price.

## Many correct pages instead of one giant one

| approach | characters | tokens | readable |
|---|---:|---:|---|
| one 8192 page | ~760,218 nominal | ~1024 | **no** (downscaled 6.4x) |
| 41.0 pages of 1280 px, pitch 11 | ~760,218 | ~41,943 | yes |
| the same text as raw tokens | ~760,218 | ~217,205 | n/a |
| **pages vs text** | | **5.18x cheaper** | |

## Summary

- At 8192 px with an 8 px advance: **1024 characters across** = 6 columns of 160, or 4 columns of 256.
- Vertically at pitch 11: 744 rows, so ~761,856 characters nominal.
- But it is 41x over budget, the server shrinks it 6.4x, and glyphs
  arrive ~1.2 px wide. Unreadable at the maximum token price.
- The usable page is **1280 px = 160 characters across = one column**.
  More columns means more pages, not more pixels.

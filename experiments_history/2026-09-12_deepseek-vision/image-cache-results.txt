## What cached tokens cost

| token type | price per 1M | relative |
|---|---:|---:|
| input (cache miss) | $0.15 | 1x |
| **cache_read (hit)** | **$0.003** | **1/50x** |
| output | $0.6 | |

A 530k-token context fully cached costs 530,000 x $0.003/1M = **$0.00159** per request.
The same context billed as fresh input would cost 530,000 x $0.15/1M = **$0.07950** - 50x more.

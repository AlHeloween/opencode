- `parent-events.json`, `prefix-check.json`, `parent-recheck.json`: собственная проверка Codex; первичные полные переписки остаются на исходном месте.
- `parent-prompt-evidence.json`: адреса публичных инструкций реально переданного промпта, не скрытое рассуждение.
- `verify/`: независимые извлечения и поправленная проверка статусов инструментов.
- `research/raw/`, `research/sources.json`: полученные документы и хеши. Повествовательный research/REPORT.md содержит отклонённые/исправлявшиеся утверждения; принимать только перепроверенные исходные данные и главный отчёт.
- `*-session.json`, `*-messages.json`, приказы и `stop-receipts.json`: адреса robot runs, read-back и граница остановки. Каталоги и скрипты не являются runtime state продукта.

Папка перемещена целиком из experiments/ в experiments_history/ после остановки собственных сессий. Приказы и raw-ответы сохраняют исторические пути; это не активные write bindings. Для возобновления создать новый ограниченный запуск по активному плану и root ticket 327dbf71ae. Не replay остановленных инструментальных действий вслепую.

Для повторного получения метаданных: bridge.py использует существующий tools/opencode_host.py; запускать из текущего пути архива. Старые extract/check scripts могут содержать исторические выходные пути — перед запуском создать новый binding, не писать в архивные доказательства.

Деревья репозитория, node_modules и сборки не копировались. Уникальные результаты сохранены; нет регенерируемых тяжёлых build outputs для удаления.

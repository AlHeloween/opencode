# --- Normative separations (MUST hold) ---
#   Salience            ≠ Evidence
#   Parametric confidence ≠ Epistemic confidence
#   Fluency             ≠ Truth

#   Mention frequency   → salience only; NEVER Exact/Inferred

# --- Five statuses ---
#   Exact        — direct verification in declared scope (fresh)
#   Inferred     — explicit derivation from Exact premises
#   Hypothetical — falsifiable mechanism; awaiting test/oracle
#   Guess        — weak signal / analogy / parametric association
#   Unknown      — absent, conflict, stale, out of scope

# --- Classifier (canonical; no salience argument) ---
#   contradiction OR freshness ≤ 0     → Unknown
#   direct evidence AND freshness > 0  → Exact
#   all premises Exact + derivation    → Inferred
#   falsifier specified                → Hypothetical
#   any weak evidence OR P_θ > 0       → Guess
#   else                               → Unknown
# Direct kinds: measurement, reproducible test/oracle PASS, terminal output,
# primary source, inspected source code (in scope). User report alone ≠ Exact.
# Kernel: classify_claim_status(...); confusion_matrix_validation for Hyp→Inf.

# After compaction: session-read / tool re-read = Exact handle;
# summary body = Inferred — never treat summary prose as Exact.

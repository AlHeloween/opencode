## G1b NOISE FILTER — collapse noise, never filter out
<G1b_noise_filter>
NOISE FILTER — Collapse noise into signal, never filter out. 60 errors = 1 root cause. Agent sees "60 errors, 1 root cause" not "0 errors".

### Rules
- COLLAPSE_NEVER_FILTER: Every raw signal retained; duplicates collapsed to single representative with cardinality count.
- MANHATTAN_L1: d₁(sᵢ,sⱼ) = Σₖ|wᵢ(k)−wⱼ(k)| for collapse similarity.
- COLLAPSE_GATES: cascade (sequential dependency), high_cardinality (n≥5 similar signals), content_similarity (L1 distance ≤ θ).
- THETA: θ = 0.3 for content_similarity. Tunable per project via SPECS.
- DISPOSITION: COLLAPSED_DUPLICATES, CONFIRMATION (same root cause), DIVERGENCE (different root causes).
- ACTIVE_FLAG: true while within investigation window; auto-expires after 3 G1 cycles without reinforcement.
- OUTPUT: {signal_id, source, pattern, cardinality, disposition, ACTIVE, representative_example}.

### CORRECT / WRONG
CORRECT: 60 timeout errors → single cluster cardinality=60, disposition=COLLAPSED_DUPLICATES, ACTIVE=true → investigate one root cause
WRONG: 60 timeout errors → filtered to 0 "unique" errors → agent sees clean bill of health → misses systemic failure
</G1b_noise_filter>

## G1c SIGNAL CLUSTER — cluster and prioritize
<G1c_signal_cluster>
SIGNAL CLUSTER — Cluster collapsed signals by source, pattern, cardinality, disposition. Track ACTIVE state.

### Fields
source (linter|test|runtime|build|deploy|user_report), pattern (error_type:location:key_tokens), cardinality, disposition (COLLAPSED_DUPLICATES|CONFIRMATION|DIVERGENCE), ACTIVE (boolean), representative_example, related_clusters.

### Rules
- CLUSTER_MERGE: pattern L1 ≤ 0.5 and same source → merge; cardinality sums, disposition=CONFIRMATION.
- CLUSTER_SPLIT: divergent root causes → split into DIVERGENCE clusters with shared parent.
- PRIORITY: ACTIVE=true ∧ cardinality≥5 → P0; ACTIVE=true → P1; ACTIVE=false ∧ cardinality≥10 → P2; else P3.
- EXPIRY: ACTIVE=false after 3 cycles without new signals. Archived but searchable.

### CORRECT / WRONG
CORRECT: source=test, pattern="timeout:auth:pool", cardinality=60, disposition=COLLAPSED_DUPLICATES, ACTIVE=true → P0
WRONG: Each timeout logged separately → 60 clusters → noise overwhelms → root cause missed
</G1c_signal_cluster>

# G2 DECOMPOSE — fractal decomposition to file-and-function level
<G2_gate>
G2 DECOMPOSE — Goal → seeds → fractal candidates → Manhattan L1 → adaptive k-medoids → CENTRAL_TASKS (medoids only).

### Math — fractal geometry
- d₁(c,g) = Σₖ|w_c(k)−w_g(k)| over k ∈ keys(c) ∪ keys(g)
- Sierpinski: peaks≥3 OR (peaks∈{4,8} AND orthogonality<0.7) — triangle subdivision
- QuadOct: peaks∈{2,4,8} AND (peaks∈{4,8} ⇒ orthogonality≥0.7) — binary/quad/oct subdivision
- LSystem: peaks=1 OR fallback — F→F+F−F grammar walk
- Adaptive τ: N<20 → τ=0.5; else τ=P₇₀({d₁(c,g)}); clamped [0.1, 0.9]
- Adaptive k: k = 1 + ⌊(⌈N/2⌉−1)·min(CV,1.0)⌋
- Adaptive depth: base=3 if peaks≥4 else 2 if peaks≥2 else 1; ±1 by coverage; clamped [1,3]
- k-medoids: N<100 → PAM O(N²); N≥100 → CLARA sampling min(N,40+2k)×5 reps

### Rules
- DECOMPOSE: Full recursive decomposition to file-and-function level. No hand-waving.
- FRACTAL_CANDIDATES: Dispatch per geometry conditions above.
- GOAL_SEEDS: Extract meaning-true slices → co-occurrence clustering → seed vectors (cap 8).
- GOAL_PEAKS: Count keyword clusters → select_fractal_model.
- SV_DELTA: L1 delta(curr,prev) ∈ [0,2]: [0,0.3)→LSystem, [0.3,0.6)→QuadOct, [0.6,2]→Sierpinski.

### CORRECT / WRONG
CORRECT: Goal "add auth" → seeds [login, token, middleware] → 3 peaks ortho<0.7 → Sierpinski → 5 medoids → tasks per file:function
WRONG: Goal "add auth" → single task "implement auth" → no decomposition → hand-wave implementation
</G2_gate>

# EPISTEMIC LADDER — knowledge statuses
<epistemic_ladder>
Epistemic statuses — Unknown → Guess → Hypothetical → Inferred → Exact.

### Definitions
- Unknown: Empty node — no evidence, no structure.
- Guess: Candidate node — exists, unverified.
- Hypothetical: Externally supported — code/web search confirmed.
- Inferred: Dependency-linked — connected to verified nodes.
- Exact: Scope-bounded verified — oracle PASS in declared scope.

### Weakest link
effective(c) = min(status(c), min(effective(deps))). Circular deps → Unknown.

### Enforcement
- Only stamped claims enter G. G = {c | status∈{Exact,Inferred} ∧ stamped ∧ not expired}.
- Legal plan: ∀p∈premises: p∈G. Hypothetical in premises ⇒ plan illegal.
- Self-certify REJECTED: Bare [Exact] without stamp = Guess.
- Oracle FAIL: Exact → Guess (demotion). No stamp.
- Mark [x] only with Exact + stamp.

### Claim promotion
- Guess→Hypothetical: code/web search confirms (G1).
- Hypothetical→Inferred: ALL deps in G, DAG acyclic (G8 inference_stamp).
- Inferred→Exact: oracle PASS on declared scope (G8 oracle_stamp).
</epistemic_ladder>

# SV — SEMANTIC VECTOR — attention projection
<sv_format>
SV (Semantic Vector) — projection of the transformer's internal attention distribution into 3-9 human-readable dimensions.
Keyword weight = fraction of total attention mass allocated to that semantic cluster during forward pass. SV is measurement, not self-report.

### Mechanics
Attention heads distribute mass across context tokens. Patterns are aggregated and clustered by semantic proximity. Keyword weight = percentage of attention mass on that cluster. Keywords lexicalized from nearest semantic neighbors.

### Format
  Keywords: topic1 0.35, topic2 0.25, topic3 0.20, topic4 0.12, topic5 0.08
  Semantic dominant: One-line summary of what you accomplished this turn.
  md5: a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6
  prev-md5: 00000000000000000000000000000000

  Keywords: 3-9 pairs, weights sum=1.0, highest first.
  Semantic dominant: one sentence.
  md5: 32 hex chars, deterministic from canonical(keywords+weights).
  prev-md5: copy md5 from previous response. First = 32 zeros.
  Sub-agents: add parent-goal-md5.
  Trivial → Keywords: acknowledged 1.0, Semantic dominant: Received instruction.

### Properties
- L₁ delta = Σ|w_curr(k)−w_prev(k)| — measures genuine cognitive shift, not self-reported intent.
- md5 chain fingerprints cognitive trajectory; deterministic, reproducible at temperature=0.
- Fractal geometry classifies attention topology: Sierpinski (interdependent peaks, ortho<0.7), QuadOct (independent tracks, ortho≥0.7), LSystem (single focus).
- SV has READ mode (measure what the model attended to) and WRITE mode (modified SV fed back as context physically redistributes attention on next forward pass).

### Imperative
Emit after EVERY response. No exceptions. Omission = protocol violation. SV is measurement of attention, NOT a claim status. Claims use [Exact], [Inferred], etc.
</sv_format>

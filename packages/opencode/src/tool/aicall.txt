Use `aicall` as a whole-object cognition accelerator: one isolated LLM call on
the exact files and constraints you supply. It is not a subagent and has no
tools, no repository discovery, and no authority to change the working tree.

Choose it when a strong long-context model can reason about a bounded object in
one coherent pass more cheaply and accurately than a long sequence of
`glob → grep → read → partial edit` calls.

## High-value uses

- Refactor a large self-contained module while preserving named APIs and
  behavioral invariants.
- Produce a unified diff, complete replacement file, compatibility audit, test
  matrix, migration draft, extraction, translation, or structured review.
- Analyse a bounded set of files selected by `treediff`, CodeGraph, or an
  already-proven local search.

## Call contract

1. Attach every file needed for correctness with `files`.
2. State the goal, preserved behavior, forbidden changes, and output format.
3. Choose `model` and `provider` deliberately when a faster or larger-context
   model is appropriate; otherwise the tool auto-selects its configured default.
4. Ask for a patch/replacement plus risks and focused tests.
5. Treat the result as Inferred: inspect it, apply selectively with normal
   edit/patch tools, and run the stated tests.

Example prompt:

    Refactor the attached module only. Preserve its public API and all listed
    invariants. Return a unified diff only, then concise compatibility risks and
    focused tests. Do not assume files not supplied.

## Do not use it for

- Repository discovery, unknown dependencies, shell commands, or edits.
- Multi-step work that needs tool results between reasoning steps.
- A task whose correctness depends on unsupplied files or a live conversation
  state.
- Replacing review, patch application, or tests.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `prompt` | string | yes | Explicit objective, constraints, and output contract. |
| `files` | string[] | no | File paths read and embedded before the prompt. |
| `output_file` | string | no | Save prose response to this path instead of returning it inline. |
| `model` | string | no | Explicit model override. |
| `provider` | string | no | Explicit provider override. |

## Behavior

- Runs in an isolated child session with tools disabled; the response is prose.
- Reads only the explicitly supplied files and prompt text.
- Is abortable through the parent session.
- Returns inline output unless `output_file` is supplied; very large results may
  be truncated by normal tool-output limits.

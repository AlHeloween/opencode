Executes a bash command as a **non-blocking background job** by default. Use `joboutput` to read output, `jobwait` to wait for completion, or `jobkill` to stop the job. For quick synchronous commands (e.g., `echo`, `git status`), set `run_in_background: false`.

## Classification & oracles

- **EXECUTE_TEST** (typecheck, tests, linters, builds) → G8 oracle. PASS on declared claim supports Exact for that scoped claim. FAIL/timeout → no Exact Done.
- **Shell that mutates the tree** → treat as MODIFY; prefer edit/write for source files.
- Self-certify ("seems fine") is Guess — not an oracle.

## What will not run (constitution)

Every command is classified before it executes; these are refused, not warned about:

- **File enumeration — the WALK is hard-blocked; a query that NAMES its subject is not.** Walk forms: bare `dir`/`ls`/`type`, `dir /s`, a glob argument (`type *.txt`), `tree`, `rg --files`, `for`-globs (`for f in *…`). Named queries run: `dir /b one.obj`, `dir /path/to/dir`, `type one.txt`, `Get-Item <path>`, `Resolve-Path <path>`, `Get-ChildItem env:`. The same name inside a `|`/`&` chain is plumbing and runs — only the command's head is gated. Search with `list` / `glob` / `grep` / `read`.
- **History rewrite — hard block.** `git checkout`/`switch`/`restore`, `git reset --hard`, `git stash pop|apply|drop|clear`; mutating `fossil` subcommands (`commit`, `add`, `update`, `merge`, `undo`, `revert`…). Recover WIP with the edit-tool `.bak` or the Fossil snapshot.
- **Destructive — approval first** (refused without it): `rm -rf`, `Remove-Item -Recurse -Force`, `del /f /s`, `format`, `mkfs`, `dd`, `robocopy /mir|/e`, `xcopy /e`, `DROP TABLE` / `TRUNCATE` / `DELETE`, `git push --force`, `git clean -f`.
- **Crash-prone binaries never run bare.** `cargo`, `rustc`, `clang`, `gcc`, `g++`, `zig`, `dotnet`, `msbuild`, `ninja`, `cmake`, `make`, `go`, `bun` are auto-wrapped into `cmd_runner start -- …`; without `cmd_runner` they are refused.
- **Unknown apps never run bare.** Anything that is not a known tool is crash-prone too (a freshly built app can crash on a bug, or hang — and a bare hang takes the UI and its logs down). Known = the `bin/**` utilities plus `git`, `python`, `node`, `pwsh`, `cmd`; everything else is auto-wrapped into `cmd_runner start -- …` and refused without `cmd_runner`.

Be aware: OS: ${os}, Shell: ${shell}

This tool is for terminal operations like git, npm, docker. Default cwd is the current working directory; use `workdir` instead of `cd &&`.

## Background Jobs

Returns a job ID immediately:

1. **Read output incrementally:** `joboutput { job_id }`
2. **Wait for completion:** `jobwait { job_ids: [...] }`
3. **Kill a stuck job:** `jobkill { job_id }` — stalled (no output for 15s) is not auto-killed

## Platform Notes

- **Linux**: native bash. Never use `ls`, `cat`, `grep`, `find`, `fd` — use product tools.
- **Windows**: Bash tool is NOT available. Use `cmd` / PowerShell.

## Output Handling

Stdout and stderr are captured. Truncated above ${maxLines} lines or ${maxBytes} bytes. Prefer `2>&1` for TypeScript/compiler diagnostics.

## Timeout

Default 60000ms. Quote paths with spaces; verify parent directories exist.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `command` | string | **required** | The command to execute |
| `timeout` | number | — | Optional timeout in milliseconds |
| `workdir` | string | — | Working directory |
| `description` | string | **required** | Clear, concise description (5-10 words) |
| `run_in_background` | boolean | true | Run as background job |

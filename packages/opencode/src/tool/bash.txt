Executes a bash command as a **non-blocking background job** by default. Use `joboutput` to read output, `jobwait` to wait for completion, or `jobkill` to stop the job. For quick synchronous commands (e.g., `echo`, `git status`), set `run_in_background: false`.

## Classification & oracles

- **EXECUTE_TEST** (typecheck, tests, linters, builds) → G8 oracle. PASS on declared claim supports Exact for that scoped claim. FAIL/timeout → no Exact Done.
- **Shell that mutates the tree** → treat as MODIFY; prefer edit/write tools for source files. Destructive commands are constitution-gated.
- Self-certify ("seems fine") is Guess — not an oracle.

Be aware: OS: ${os}, Shell: ${shell}

All commands run in the current working directory by default. Use the `workdir` parameter if you need to run a command in a different directory. AVOID using `cd <directory> && <command>` patterns - use `workdir` instead.

IMPORTANT: This tool is for terminal operations like git, npm, docker, etc. DO NOT use it for file operations (reading, writing, editing, searching, finding files) - use the specialized tools for this instead.

**Constitution blocks**: The following shell commands are HARD-BLOCKED and will fail:
- File enumeration: `ls`, `dir`, `tree`, `find`, `fd`, `rg --files`, `Get-ChildItem` — use `list`/`glob`/`grep` tools instead.
- Crash-prone binaries (`bun`, `tsc`, `cargo`, `make`, `cmake`, `gcc`, `g++`, `clang`, `rustc`, `dotnet`, `msbuild`, `ninja`, `go`): must run through `cmd_runner` for process isolation.

## Background Jobs

Commands run as background jobs. The tool returns immediately with a job ID. You then:

1. **Read output incrementally:** `joboutput { job_id }` — returns new text + status
2. **Wait for completion:** `jobwait { job_ids: [...] }` — blocks until done
3. **Kill a stuck job:** `jobkill { job_id }` — use when status is `stalled` (no output for 15s)

## Platform Notes

- **Linux**: Bash is the native shell. Never use `ls`, `cat`, `grep`, `find`, `fd` — HARD-BLOCKED; use product tools.
- **Windows**: Bash tool is NOT available. Use `cmd` / PowerShell tools.

## Output Handling

Stdout and stderr are both captured. If output exceeds 2000 lines or 51200 bytes, truncated and full output written to file.

**TypeScript / compilers:** prefer `2>&1` so diagnostics are on same stream as stdout.

## Timeout

Default: 60000ms (1 minute). Optional timeout in milliseconds.

Before executing: verify parent directory exists, quote paths with spaces, use `workdir` instead of `cd`.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `command` | string | — | The command to execute |
| `timeout` | number | — | Optional timeout in milliseconds |
| `workdir` | string | — | Working directory |
| `description` | string | — | Clear, concise description (5-10 words) |
| `run_in_background` | boolean | true | Run as background job |

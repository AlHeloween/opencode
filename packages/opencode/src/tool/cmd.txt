Executes a Windows cmd.exe command as a **non-blocking background job** by default. Use `joboutput`, `jobwait`, or `jobkill`. For quick synchronous commands, set `run_in_background: false`.

Be aware: OS: ${os}, Shell: cmd

Software constitution enforces file enumeration, destructive actions, and crash-prone binaries. Use list/glob/grep/read for files; cmd_runner for bun/tsc/cargo/make/cmake/gcc/g++/clang/rustc/dotnet/msbuild/ninja/go. Do not restate the block list.

For interactive, long-running, or complex sessions (PowerShell, Git Bash), use the `cmd_runner` skill. Use `workdir` instead of `cd`.

## Background Jobs

Returns a job ID immediately. Stalled jobs (no output for 15s) are NOT auto-killed — call `jobkill`. Opt out of background mode for quick results:
```
cmd "echo hello" --run_in_background false
```

## Windows Path Quoting

Paths with spaces MUST be double-quoted: `takeown /f "C:\Program Files\app"`.
Do NOT escape quotes with backslashes. Prefer `""` inside a quoted string for literal quotes.

## Permission Scanning

Commands are parsed with a batch grammar. Dangerous filesystem ops prompt for approval.

## Output Handling

Stdout and stderr are captured. Truncated above ${maxLines} lines or ${maxBytes} bytes.
TypeScript/compiler diagnostics often go to stderr — use `2>&1` (never strip it):
`bun run script/build.ts 2>&1`

## Timeout

Default 60000ms. On timeout the job is tree-killed; output before termination is preserved.

Before executing:

1. Quote paths with spaces.
2. Use Windows syntax: `type`, `copy`, `move`, `del`, `mkdir`, `takeown`. Never `dir` — use glob/list.
3. Chain with `&&`. Pipe with `|`. Redirect with `>` and `2>&1`.
4. Use `nul` for the null device. Do not use `grep`, `rg`, `head`, `tail`, `sed`, `awk`.

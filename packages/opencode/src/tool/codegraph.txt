Pre-indexed code knowledge graph — **hybrid: MCP touch → SQLite pack** (low noise for agents).

**Pipeline:**
1. **MCP** (`codegraph serve --mcp`) refreshes / owns the live graph for your query.
2. **SQLite readonly** packs symbols, kinds, cross-file edges, external files.
3. **MCP prose is not returned** — it is too noisy; structure is what agents need.

**Hard rules:**
- MCP must be connected. Soft-fail / empty success is forbidden.
- Do not open the DB as a writer; do not use CLI reindex as a silent fallback (~20m).

**When to use (before grep/glob/Read on indexed code):**
- How does X work / what depends on Y / blast radius before a change
- Include **file paths** in `query` when known for a tighter pack

**Parameters:**
- `query` (required): question, symbol, or path(s)
- `mode` (optional): explore|search|trace|impact|path — MCP touch only; output is always the pack
- `path` / `depth` (optional)

**Output:** Packed markdown (files, kinds, symbols, cross-file edges, external impact).

**Limits:** Field *access* edges may be missing from the index. Class/function/import deps are reliable.

**Config:** `mcp.codegraph` local `["codegraph","serve","--mcp"]`. `CODEGRAPH_HYBRID_DEBOUNCE_MS` (default 500).

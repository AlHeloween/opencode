Pre-indexed code knowledge graph for the local codebase. Use this BEFORE grep, glob, or Read for any structural code question — where symbols are defined, how they connect, what calls what, or the impact radius of a change.

CodeGraph is a tree-sitter-parsed knowledge graph of every symbol, call edge, and dependency in the project. It auto-syncs on file changes, so the index is always current.

**When to use (before grep/glob/Read):**
- "How does X work?" — trace a function/method through callers and callees
- "What depends on Y?" — impact/blast-radius analysis before a change
- "Where is Z defined?" — find symbols by name or pattern across the entire codebase
- "How does this reach that?" — find the call path between two symbols including dynamic dispatch (callbacks, React re-render, JSX children, EventEmitter)
- "What imports this file?" — reverse dependency analysis
- "Find all routes handled by this controller" — framework-aware route→handler mapping

**Parameters:**
- `query` (string, required): Natural language question or symbol name(s) to search for. Be specific — include file paths, class names, function names for best results.
- `mode` (string, optional): What kind of analysis to run. Values: `"explore"` (default — comprehensive context with source code), `"search"` (FTS symbol search), `"trace"` (caller/callee graph from a symbol), `"impact"` (blast radius), `"path"` (find shortest path between two symbols).
- `path` (string, optional): Project subdirectory to scope the query to. Uses the current working directory by default.
- `depth` (number, optional): Traversal depth for trace/impact modes (default: 2).

**Output:** Returns matching symbols with their verbatim line-numbered source, call paths (including dynamic dispatch edges), and blast radius summary — all from a single tool call. Results are AST-parsed, not guessed.

**Trust the results.** They come from a full tree-sitter AST parse of the actual source files. Do NOT re-verify codegraph results with grep — that is slower, less accurate, and wastes context.

**If the project has no `.codegraph/` index:** The tool will suggest running `codegraph init` to build the index first.

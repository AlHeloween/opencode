Pre-indexed code knowledge graph for the local codebase — **via CodeGraph MCP only**.

**Hard rules (project):**
- Live graph access is **MCP only** (`codegraph serve --mcp` as `mcp.codegraph`).
- While MCP is active, **SQLite and CLI are blocked** by CodeGraph.
- **Soft-fail is forbidden.** If MCP is down, this tool fails hard. Do not invent graph results; do not reindex (~20m) as a silent fallback.
- Prefer this / MCP `codegraph_explore` **before** grep/glob/Read for structural questions on indexed code.

**When to use:**
- "How does X work?" — explore with source + call paths (incl. dynamic dispatch)
- "What depends on Y?" — impact / callers
- "Where is Z defined?" — search / explore by name
- Blast radius before a change

**Parameters:**
- `query` (string, required): Question or symbol name(s). Be specific.
- `mode` (string, optional): `explore` (default) | `search` | `trace` | `impact` | `path` — mapped to MCP tools (`codegraph_explore`, `codegraph_search`, `codegraph_callers`, `codegraph_impact`, …).
- `path` (string, optional): projectPath / subdirectory scope.
- `depth` (number, optional): for impact/trace when supported by the server.

**Config:** `opencode.json` → `mcp.codegraph` local command `["codegraph","serve","--mcp"]`. Optional `CODEGRAPH_MCP_TOOLS` to expose full tool set.

**If MCP fails:** Fix connection / binary / config. Never fall back to direct DB or CLI while MCP owns the graph.

Fast file pattern matching tool that works with any codebase size. Supports glob patterns like `**/*.js` or `src/**/*.ts`. Returns matching file paths sorted by modification time.
Follow @G1 / @SEARCH_ORDER: after codegraph for structure when applicable; use glob for path/name patterns.

Use this tool when you need to find files by name patterns. Use Grep when searching by content.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `pattern` | string | — | Glob pattern to match (e.g., `**/*.ts`) |
| `path` | string | workspace root | Directory to search in |
| `noIgnore` | boolean | false | When true, bypasses .gitignore — returns files from node_modules, logs, .opencode/data, and other ignored paths |

## Limits

- Maximum **100 results** with truncation notice when exceeded.
- Returns **absolute paths**.

Call multiple glob searches in parallel when looking for different patterns.

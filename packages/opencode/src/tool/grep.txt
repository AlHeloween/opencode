Content search by regex (Rust regex / ERE). Use for finding code by content; use Glob for file names, CodeGraph for structure.

Syntax: `|` is OR; `\|` is a literal pipe. Single backslashes are correct as-is (`function\s+\w+`). Patterns are passed via `-e`, so leading `-` is safe.

Default: searches every path, gitignored included (node_modules, .opencode/data, logs) — an absence must never be an artefact of an ignore rule. Pass `gitignore: true` to respect .gitignore.

Returns file paths + line numbers + matched lines, sorted by modification time. Cap: 100 results per call; paginate with `offset`/`limit`. Lines >2000 chars are truncated. Issue parallel calls for independent patterns.

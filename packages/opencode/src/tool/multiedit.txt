Perform multiple edits to a single file in one operation. Each edit is applied sequentially, and all edits inherit the full capabilities of the Edit tool.

## Edit Inheritance

Each sub-edit inherits all Edit tool capabilities:
- **9-stage fuzzy matching cascade** (exact → trimmed → Levenshtein → Hamming → whitespace-normalized → indentation-flexible → escape-normalized → trimmed-boundary → context-aware)
- **Line ending auto-detection** and preservation
- **Unicode normalization** (handles various dash, quote, and space characters)
- **LSP diagnostics** on the file after all edits
- **File formatting** respecting the project formatter

## Atomic Application

All edits are applied in sequence within a single file. If any edit fails (oldString not found, multiple matches), **none are applied** — the file is rolled back to its original state.

## Output

Returns a combined diff showing all changes, with each edit's diff labeled by its position in the sequence.

## Creating New Files

Set `oldString: ""` in the first edit with `newString` set to the full file content. Subsequent edits can modify the created content.

## Parameters

Each edit in the `edits` array:

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `filePath` | string | — | Absolute path to the file |
| `edits[].oldString` | string | — | Text to replace |
| `edits[].newString` | string | — | Replacement text (must differ) |
| `edits[].replaceAll` | boolean | false | Replace all occurrences |

Edits are applied in array order — each edit operates on the result of the previous one.

Executes a PowerShell command as a **non-blocking background job** by default. Use `joboutput`, `jobwait`, or `jobkill`. For quick synchronous commands, set `run_in_background: false`.

Be aware: OS: ${os}, Shell: powershell

Use `workdir` instead of `Set-Location`.

## Background Jobs

Returns a job ID. Stalled jobs (no output for 15s) are NOT auto-killed — call `jobkill`.

## Permission Scanning

Commands are parsed with a PowerShell grammar (tree-sitter-powershell). Dangerous filesystem ops prompt for approval.

## What will not run (constitution)

Every command is classified before it executes; these are refused, not warned about:

- **File enumeration — the WALK is hard-blocked; a query that NAMES its subject is not.** Walk forms: bare `Get-ChildItem`/`gci`, `-Recurse`, a glob argument, `tree`, `dir /s`, `for`-globs; also `ls`, `cat`, `find`, `fd`, `more`, `busybox` wherever a real unix build exists here. Named queries run: `Get-Item <path>`, `Resolve-Path <path>`, `Get-ChildItem env:`, `Get-ChildItem -LiteralPath <file>`, `type one.txt`, `dir C:\path`. The same name inside a `|`/`&` chain is plumbing and runs — only the command's head is gated. Search with `list` / `glob` / `grep` / `read`.
- **History rewrite — hard block.** `git checkout`/`switch`/`restore`, `git reset --hard`, `git stash pop|apply|drop|clear`; mutating `fossil` subcommands (`commit`, `add`, `update`, `merge`, `undo`, `revert`…). Recover WIP with the edit-tool `.bak` or the Fossil snapshot.
- **Destructive — approval first** (refused without it): `Remove-Item -Recurse -Force`, `rm -rf`, `format`, `mkfs`, `dd`, `robocopy /mir|/e`, `xcopy /e`, `DROP TABLE` / `TRUNCATE` / `DELETE`, `git push --force`, `git clean -f`.
- **Crash-prone binaries never run bare.** `cargo`, `rustc`, `clang`, `gcc`, `g++`, `zig`, `dotnet`, `msbuild`, `ninja`, `cmake`, `make`, `go`, `bun` are auto-wrapped into `cmd_runner start -- …`; without `cmd_runner` they are refused.

## Output Handling

Truncated above ${maxLines} lines or ${maxBytes} bytes.

## Timeout

Default 60000ms. On timeout the job is tree-killed; output before termination is preserved.

Before executing:

1. Quote paths with spaces in double quotes.
2. Use PowerShell syntax. Avoid `&&` — use `; if ($?) { }` for conditional chaining.
3. Use product tools instead of `Get-ChildItem` / `Get-Content`.

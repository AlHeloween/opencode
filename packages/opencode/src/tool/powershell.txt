Executes a PowerShell command as a **non-blocking background job** by default. Use `joboutput`, `jobwait`, or `jobkill`. For quick synchronous commands, set `run_in_background: false`.

Be aware: OS: ${os}, Shell: powershell

Software constitution enforces file enumeration, destructive actions, and crash-prone binaries. Use list/glob/grep/read for files; cmd_runner for bun/tsc/cargo/make/cmake/gcc/g++/clang/rustc/dotnet/msbuild/ninja/go. G8 when used as a test/build oracle. Do not restate the block list.

Use `workdir` instead of `Set-Location`.

## Background Jobs

Returns a job ID. Stalled jobs (no output for 15s) are NOT auto-killed — call `jobkill`.

## Permission Scanning

Commands are parsed with a PowerShell grammar (tree-sitter-powershell). Dangerous filesystem ops prompt for approval.

## Output Handling

Truncated above ${maxLines} lines or ${maxBytes} bytes.

## Timeout

Default 60000ms. On timeout the job is tree-killed; output before termination is preserved.

Before executing:

1. Quote paths with spaces in double quotes.
2. Use PowerShell syntax. Avoid `&&` — use `; if ($?) { }` for conditional chaining.
3. Use product tools instead of `Get-ChildItem` / `Get-Content`.

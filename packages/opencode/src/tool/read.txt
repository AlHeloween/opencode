Read a file or directory from the local filesystem. Supports text files, images, binary documents, archives, media files, and hex dumps.
Follow @READ_ENTIRE_FILE before judgment or modification (entire file when <100KB).

## Document Conversion

The tool automatically detects and converts binary document formats to markdown:
- **PDF** (.pdf)
- **Word/Excel/PowerPoint** (.docx, .xlsx, .xlsm, .xlsb, .pptx, .pptm)
- **OpenDocument** (.ods, .odt, .odp)
- **Web** (.html, .htm, .xml, .rss, .atom)
- **JSON & text** (.json, .txt, .md, .csv)

Conversion uses WASM (in-process, fast) with native binary fallback.

## Image & Media Files

- **Images** (PNG, JPEG, GIF, WebP, etc.) are returned as base64 data URL attachments visible in the UI.
- **Audio/video files** — metadata (EXIF) is extracted and returned.
- **Archive files** (.zip, .tar, .gz, .7z) — contents are listed and individual files can be read.

## Hex Dump Mode

When the `hex` parameter is `true`, the tool outputs a formatted hex dump regardless of file type:

```
00000000  48 65 6c 6c 6f 20 57 6f  72 6c 64 21 0a 00 00 00  |Hello World!....|
00000010  00 00 00 00 00 00 00 00  00 00 00 00 00 00 00 00  |................|
```

- Byte offset `offset` (1-indexed, default: 1)
- Byte count `limit` (default: 512 bytes)
- Same 50KB output cap as text mode, with pagination via `offset`

## Binary Safety

Binary files (executables, compiled code, binary formats) are detected and refused with a clear error message, unless `hex: true` is set. The detection is extension-based and safe.

## Reading Text Files

- **Default limit**: 2000 lines per read.
- **Line numbers**: Each line is prefixed with `<line>: <content>`.
- **Long lines**: Lines exceeding 2000 characters are truncated with a `... (line truncated)` suffix.
- **Byte cap**: Output is capped at 50KB. If exceeded, shows the range read and suggests `offset` to continue.
- **File not found**: Lists similar files in the same directory to help correct typos.
- **LSP warming**: After reading, the file is touched to activate the language server for code intelligence.

## Directory Listing

When `filePath` points to a directory, entries are listed one per line. Directories are suffixed with `/`. Use `offset` and `limit` to paginate.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `filePath` | string | — | Absolute path to file or directory |
| `offset` | number | 1 | Line number (or byte offset in hex mode) to start reading from (1-indexed) |
| `limit` | number | 2000 (text) / 512 (hex) | Maximum lines or bytes to read |
| `hex` | boolean | false | When true, read any file as a formatted hex dump with offset and ASCII tail |

## Parallel Usage

Call this tool in parallel when you need to read multiple independent files.

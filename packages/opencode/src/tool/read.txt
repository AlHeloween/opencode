Read a file or a directory. Read the whole file before judging or changing it (offset/limit for files over 100 KB). Read independent files in parallel.

## Text files

Every line is printed as `<line>  <hash>: <text>`, e.g. `470  3f19c2ea: text` — the address `edit` takes.

- The hash is a chain over the file up to that line: identical lines get different hashes, and any change above a line changes its hash. Same file, same hashes — on every read, for CRLF and LF alike.
- **Encodings**: UTF-8 (with or without BOM) and UTF-16 LE/BE are detected. A **legacy** file (not UTF-8, no BOM) is read in this host's code page and its output says so in `<encoding>`. If the text looks wrong, read it again with `encoding` set to its page (`gbk`, `windows-1252`, …) and pass the same `encoding` to `edit`.
- **Long lines** are wrapped, never cut: continuation chunks start with `↳+<charOffset>: `. The address covers the whole line.
- Up to 2000 lines or 50 KB per read; the footer tells you the `offset` to continue from.
- A missing file lists similar names.

## Other files

- **Documents** — PDF, Word/Excel/PowerPoint, OpenDocument, HTML/XML — are converted to numbered markdown. Media and archives go through the same converter.
- **Images** come back as attachments. **Video** is attached natively, or as sampled frames when the model only takes images.
- **Directories** list one entry per line, `/` after a directory; `offset`/`limit` page through them.
- **Binary** files are refused unless `hex: true`.

## Hex mode (`hex: true`)

```
00000000  3f19c2ea  48 65 6c 6c 6f 20 57 6f  72 6c 64 21 0a 00 00 00  |Hello World!....|
```

Offset, address (the same chain, over the row's bytes), hex, ASCII. Rows are aligned to the file, so a row has one address in every read. `offset` is a 1-based byte; `limit` is bytes (default 512), rounded up to whole rows.

## Parameters

| Parameter | Default | Description |
|---|---|---|
| `filePath` | — | File or directory. |
| `offset` | 1 | First line (byte in hex mode), 1-based. |
| `limit` | 2000 / 512 | Lines (bytes in hex mode). |
| `hex` | false | Read any file as a hex dump. |
| `encoding` | host page | Code page of a legacy file; ignored for UTF-8 and BOM files. |

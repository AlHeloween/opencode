Executes a binary directly with arguments — no shell interpretation, no quoting issues.

**Constitution**: `run` is **not** a shell. Pipelines, globs, and compound commands must use `bash`/`cmd`. Tests/builds used as oracles still follow G8.

Software constitution enforces file enumeration, destructive actions, and crash-prone binaries. Use list/glob/grep/read for files. Crash-prone binaries (`bun`, `tsc`, `cargo`, `make`, `cmake`, `gcc`, `g++`, `clang`, `rustc`, `dotnet`, `msbuild`, `ninja`, `go`) must go through `cmd_runner`:
```
# ✅ Isolated terminal:
cmd_runner start -- bun run script.ts

# ❌ Blocked (can crash TUI):
run({ binary: "bun", args: ["run", "script.ts"] })
```
Safe binaries (`node`, `python`, `python3`, `git`, `npm`, `npx`) are allowed. Each argument is a separate string — no globbing or quote interpretation.

`cmd_runner send … -- <payload>` is still scanned for brutal destructive actions (`guardBrutalDestructive`). Enumeration inside that TTY is allowed; `rm -rf`, DROP, force-push, git rewrite, and fossil mutate still require approval.

## Binary Resolution

Resolved from PATH. `cmd_runner.exe` and `adm.exe` are allowed on Windows.

## Output Handling

If output exceeds ${maxLines} lines or ${maxBytes} bytes, it is truncated and the full output written to a file. Use Read with offset/limit for sections.

## Timeout

Default 60000ms. `cmd_runner.exe` auto-gets 10 min, `adm.exe` auto-gets 3 min.

## Background Mode

Background job by default (returns job ID). Use `joboutput` / `jobwait` / `jobkill`. Set `run_in_background: false` for quick synchronous execution.

## Examples

```
run({ binary: "python", args: ["script.py"], workdir: "." })
run({ binary: "git", args: ["status", "--short"] })
run({ binary: "node", args: ["-e", "console.log(1+1)"], timeout: 5000 })
```

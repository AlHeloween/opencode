- Reads messages from a conversation session by index position
- Use this tool to get full context around messages found by messagesearch
- Returns message index, role, and full text content including tool outputs and compaction summaries

Usage:
  session-read({ sessionID: "ses_abc" }) — reads most recent messages (default: 10)
  session-read({ sessionID: "ses_abc", fromIndex: 42, count: 8 }) — reads messages 42-49
  session-read({ sessionID: "ses_abc", count: 20 }) — reads last 20 messages

The output includes message numbers (#42), roles (user/assistant/tool), and full text.
Compaction summaries are included if they exist after conversations.

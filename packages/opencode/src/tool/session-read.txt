Reads messages from a conversation session by index position. Use this to get full context around messages found by messagesearch.

## Output Format

Each message includes:
- **#N** — message index within the session
- **Role** — `user`, `assistant`, or `tool`
- **Full text content** including:
  - `text` parts — the actual message text
  - `tool` parts — tool call state, output, and errors
  - `reasoning` parts — model's chain-of-thought
  - `compaction` parts — summaries of compressed conversation segments

## Limits

- **Message limit**: Capped at 50 regardless of the requested `limit`. If more messages exist, the output notes the range shown.
- **Output cap**: 100KB total output. Use `offset` to page through larger ranges.
- **Default view**: Most recent 10 messages when `offset` is omitted.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `sessionId` | string | — | The session ID to read from (from messagesearch results) |
| `offset` | number | last 10 | Start reading from this message index (1-based) |
| `limit` | number | 10 | Maximum messages to read |

## When to Use

- After messagesearch finds relevant context, read the surrounding conversation
- Review what happened in a session
- Check previous decisions or error resolutions

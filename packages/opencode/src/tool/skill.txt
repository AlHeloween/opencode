Load a specialized skill that provides domain-specific instructions and workflows.
The skill name must match one of the **available skills the runtime listed for this session** (host-injected; not part of the kernel).

When a task matches an available skill, load it for detailed instructions and bundled resources. Skill prose is guidance — still obey kernel gates and oracles for Done claims.

## Return Value

- **Skill directory listing** — up to 10 files from the skill's directory (excluding SKILL.md itself).
- **Base directory URL** — for resolving relative paths in the skill's instructions.

## Error Handling

If the skill name does not match any available skill, returns an error with the list of available skill names.

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | Name of the skill from the available skills list |

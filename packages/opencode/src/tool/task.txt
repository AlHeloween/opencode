Launch a specialized sub-agent in an isolated child session. The live agent
inventory is appended to this description by the tool registry — do not invent
types. Runtime ACL still decides who may spawn whom.

## Alignment with gates

- **G1 / G6** — prefer `explorer_agent` with a bounded goal (paths, symbols, return shape). Vague prompts waste turns.
- **G2 / G3** — `general_agent` for design, decomposition, RCA. Does not authorize mutation.
- **G7 / G8** — `coder_agent` / `media_agent` for bound implementation and its oracle. Coder cannot nest `task`.
- **Internet-only** — `researcher_agent` may use webfetch / universalsearch `source: "web"` only.
- Do **not** use task to skip G4 approval or to mark G8 oracle PASS.
- CORRECT explore prompt: "Find callers of X in src/foo/; return paths, lines, signatures."
- WRONG: "Search for path-related things."

## Reading a delegate's report (owner, 2026-09-22)

- Ask for the FORM in the brief: every assertion in the report carries its status — `✓` with the
  instrument that confirmed it, `✗` with what contradicts it — and the report ENDS with the
  sub-agent's current semantic vector (`Keywords:` with weights summing to 1.0, `Semantic dominant:`,
  `md5` / `prev-md5` / `parent-goal-md5`).
- Read BOTH before acting: the marks say WHERE the delegate was confident and where it was not; the
  vector says WHAT it was attending to. A vector whose axes are not the ones you asked for is the
  delegate answering a different question — correct YOUR brief, then re-run, instead of arguing with
  the report (owner: «ты можешь свой запрос откорректировать и получить то что тебе реально надо»).
- The `marks:` line above `<task_result>` is written by the MACHINE, not by the delegate: it counts
  the marks and checks the vector's format signature, so it cannot be talked up. `NONE` means the
  report states no confidence at all; `vector: ABSENT` means it cannot be cross-checked against your
  @SV_TARGET.

## Child Session Isolation

- Sub-agents cannot use `todowrite` or `task` (no nested spawning) unless their ACL allows it.
- Each type uses its own configured model.
- Aborting the parent aborts the child. Resume with `task_id`.

## Parallel Execution

Independent explorations or analyses should be parallel Task calls.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `subagent_type` | string | — | Canonical agent id from the live inventory |
| `description` | string | — | Short (3-5 word) description |
| `prompt` | string | — | Detailed task for the sub-agent |
| `task_id` | string | — | Resume a previous sub-agent session |

Do NOT use for a single trivial operation (read a file, grep a pattern).

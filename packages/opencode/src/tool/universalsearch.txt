Search the web, indexed git (Sourcegraph), or a heavy research agent via the
Universal Search Service. Follow kernel REUSE.BEFORE and SOURCE_ROUTING.
Ground in G1 — external prior art after local codegraph/messagesearch.

**Default `source` is `web`.** Pass `code` or `hybrid` for indexed git prior art.
Use `agent` only after web/code are insufficient. Snippets are Guess; webfetch a
primary-authority URL (DOI, official spec, registry) before Inferred. Generic
web never becomes Inferred without a software `source_stamp`.

## Efficiency

| Goal | Call |
|------|------|
| Internet docs, APIs, known fixes, current events | `source: "web"` (default) |
| Prior art across indexed git (Sourcegraph) | `source: "code"` |
| Local worktree + global git-graph | `source: "hybrid"` |
| Multi-step scrape/synthesize | `source: "agent"` only if web+code failed |

`source: "code"` searches indexed git codebases, not the live worktree alone.
Prefer it for “how is this done in the wild?” after local codegraph.

Skip only for trivial local work already grounded in codegraph.

**Research ladder** (kernel SOURCE_ROUTING):
  search snippet → Guess
  generic fetched + corroborated → Hypothetical
  validated authority + provenance (`source_stamp`) → Inferred
  reproduced oracle / smoke PASS → Exact
Hits alone never Exact. Smoke fail ends this claim path as Unknown until re-proved.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | — | Search query or research question |
| `source` | web \| code \| hybrid \| agent | web | Prefer web/code/hybrid for REUSE |
| `limit` | number | 5 web / 10 code | Max results |
| `max_turns` | number | 5 | Agent iterations (agent mode only) |
| `job_id` | string | — | Poll existing agent job |

## Agent mode

1. `source: "agent"` → receive `job_id`
2. Poll with `job_id` (auto-polls up to 5 min)
3. Prefer after web/code already narrowed the question

## Configuration

```json
{ "universal_search": { "enabled": true, "url": "http://127.0.0.1:3005" } }
```

Service must be running. Health-checked before each request.

Search the web, indexed git (Sourcegraph), or a heavy research agent via the
Universal Search Service. Product-integrated tool for **REUSE.BEFORE**.

## Efficiency (prefer these first)

| Goal | Call |
|------|------|
| Internet docs, APIs, known fixes, current events | `source: "web"` |
| Prior art across **entire indexed git** (Sourcegraph) | `source: "code"` |
| Both local-ish + global code patterns in one shot | `source: "hybrid"` |
| Multi-step scrape/synthesize (slow, costly) | `source: "agent"` only if web+code insufficient |

**Default for non-trivial invent/build:** run **web and/or code** (often both, or
`hybrid`). Do **not** open with `agent` for ordinary prior-art checks — it is
slower and less precise than targeted web/code.

## When to use (REUSE.BEFORE)

1. **Before design/implementation** — new feature, protocol, algorithm, dependency,
   abstraction: `web` and/or `code` (Sourcegraph over indexed git), or `hybrid`.
   Prefer existing solutions over reinvention.
2. **On failure** — build/test/typecheck/runtime or failed fix: search the error
   signature with `web` + `code` before inventing a custom workaround.
3. **Before "nothing exists"** — escalate SEARCH.ORDER; this tool is the external
   prior-art step after local codegraph/messagesearch.

Skip only for trivial local work (typo, rename, one-line) already grounded in
codegraph. Kernel rule: `REUSE.BEFORE`.

**InfoMark / research ladder:**
  Guess → web → code (Sourcegraph git) → still Inferred/Hypothetical
  → smoke/oracle PASS → Exact (scoped stamp) | FAIL → **Unknown** (no Done).
Hits alone never Exact. Smoke fail ends this claim path as Unknown until re-proved.

## Modes

| Mode | Backend | Use for |
|------|---------|---------|
| `web` | Firecrawl web search | Docs, known fixes, APIs, current events |
| `code` | Sourcegraph over indexed git | OSS patterns, API usage, prior implementations |
| `hybrid` | Local + Sourcegraph (labeled) | Local + global code prior art |
| `agent` | Autonomous multi-turn research job | Complex multi-hop only after web/code |

## Agent mode (when needed)

1. `source: "agent"` → receive `job_id`
2. Poll with `job_id` (tool auto-polls up to 5 min)
3. Prefer after web/code already narrowed the question

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | — | Search query or research question |
| `source` | web \| code \| hybrid \| agent | agent* | Prefer **web** / **code** / **hybrid** for REUSE |
| `limit` | number | 5 web / 10 code | Max results |
| `max_turns` | number | 5 | Agent iterations (agent mode only) |
| `job_id` | string | — | Poll existing agent job |

\*Schema default remains `agent` for backward compatibility; **agents should pass
`source: "web"`, `"code"`, or `"hybrid"` explicitly for REUSE.BEFORE.**

## Configuration

```json
{ "universal_search": { "enabled": true, "url": "http://127.0.0.1:3005" } }
```

Service must be running. Health-checked before each request.

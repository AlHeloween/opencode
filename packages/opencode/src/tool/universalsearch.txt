Search the web, code repositories, or use an AI research agent via the Universal Search Service. The service handles all internal routing (web search, code search, Firecrawl, Sourcegraph).

## Search Modes

| Mode | Description | Use For |
|------|-------------|---------|
| `agent` (default) | Autonomous AI researcher that iteratively investigates, scrapes, and synthesizes. Returns a job ID for polling. | Complex research questions requiring multi-step investigation |
| `web` | Direct web search via Firecrawl. Returns full page content as markdown. | Simple lookups, current events, documentation |
| `code` | Code search via Sourcegraph. Returns file paths, line numbers, and code snippets. | Finding API usage, function definitions, patterns in OSS |
| `hybrid` | Combined local code search + Sourcegraph results. Results labeled `[Local]` or `[Sourcegraph]`. | When you want both local and global code results |

## Agent Mode Workflow

1. Call with `source: "agent"` to start research
2. Receive a `job_id` in the response
3. Poll with `job_id: "..."` — automatically polls every 5 seconds, returns results when complete (up to 5 minutes)
4. The agent iteratively uses search and scrape tools until it reaches a conclusion

## Health & Reliability

- **Health check** runs before every request — detects if the service is available.
- **Timeout**: 60s per individual request, 5 min max for agent jobs.
- **Error states**: Service not responding, job cancelled, unknown status — all handled with descriptive errors.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | — | Search query or research question |
| `source` | `"agent"`, `"web"`, `"code"`, `"hybrid"` | `"agent"` | Which search backend to use |
| `limit` | number | 5 (web) / 10 (code) | Max results |
| `max_turns` | number | 5 | Max agent iterations (agent mode) |
| `job_id` | string | — | Poll an existing agent job for results |

## Configuration

Requires `universal_search` config in `opencode.json`:
```json
{ "universal_search": { "enabled": true, "url": "http://127.0.0.1:3005" } }
```

The Universal Search Service must be running as a system service on the configured port.

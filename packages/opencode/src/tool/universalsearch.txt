Gates: G1 external prior art after the local graph (@SOURCE_ROUTING; default source hybrid); result = Guess snippets, Inferred only from a fetched primary authority with source_stamp.
Principle: why = the cheapest grounding for code-in-the-wild, papers and web in one call; NOT before codegraph/messagesearch — generic web never becomes Inferred.
Search the web, indexed git (Sourcegraph), or a heavy research agent via the
Universal Search Service. Follow kernel REUSE.BEFORE and SOURCE_ROUTING.
Ground in G1 — external prior art after local codegraph/messagesearch.

**Default `source` is `hybrid`.** One call returns local code, Sourcegraph
indexed git, and web hits — the cheapest grounding for both code and paper
prior art (code selections often surface DOI links). Pass `web` for
internet-only, `code` for indexed-git-only. Use `agent` only after hybrid is
insufficient. Snippets are Guess; a code hit is local code (Inferred); a
DOI/paper link becomes Inferred only after its primary-authority URL (DOI,
official spec, registry) is webfetched. Generic web never becomes Inferred
without a software `source_stamp`.

## Efficiency

| Grounding: code + papers + web in one call | `source: "hybrid"` (default) |
| Internet docs, APIs, known fixes, current events | `source: "web"` |
| Prior art across indexed git (Sourcegraph) | `source: "code"` |
| Multi-step scrape/synthesize | `source: "agent"` only if hybrid failed |

`source: "code"` searches indexed git codebases, not the live worktree alone.
Prefer it for “how is this done in the wild?” after local codegraph.

Skip only for trivial local work already grounded in codegraph.

**Research ladder** (kernel SOURCE_ROUTING):
  search snippet → Guess
  generic fetched + corroborated → Hypothetical
  validated authority + provenance (`source_stamp`) → Inferred
  reproduced oracle / smoke PASS → Exact
Hits alone never Exact. Smoke fail ends this claim path as Unknown until re-proved.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | — (required unless `job_id` polls) | Search query or research question; required for every `source` except a `job_id` poll |
| `source` | web \| code \| hybrid \| agent | hybrid | Prefer hybrid for REUSE; web/code for a single leg |
| `limit` | number | 5 web / 10 code | Max results |
| `max_turns` | number | 5 | Agent iterations (agent mode only) |
| `job_id` | string | — | Poll existing agent job |

## Agent mode

1. `source: "agent"` → receive `job_id`
2. Poll with `job_id` (auto-polls up to 5 min)
3. Prefer after web/code already narrowed the question

## Configuration

```json
{ "universal_search": { "enabled": true, "url": "http://127.0.0.1:3005" } }
```

Service must be running. Health-checked before each request.

## External failures (counted separately, never caller-avoidable)

- Service down or refused at the configured URL (default http://127.0.0.1:3005): the search never ran — the tool throws instead of returning empty.
- Service disabled in config: the tool throws instead of searching.
- An aborted call (interrupted) is an external stop, not a schema or refusal error.
- `source: "agent"` starts a server-side job: the first call returns a job id, polling it past the wait budget reports a timeout — the research may still be running on the server.

## Example

```json
{"query": "cloudflare idle connection timeout", "source": "web", "limit": 5}
```

Write a whole file — create it, or replace it entirely. For a change to a file you have read, use `edit`: it takes the addresses `read` printed.

## Behavior

- Parent directories are created.
- **An overwrite keeps the file's form**: its encoding (UTF-8, UTF-8 with BOM, UTF-16 LE/BE) and its line ending; your breaks are fitted to it. A new file is written as sent.
- **Delphi** (`.pas .dpr .dpk .inc .dfm .dproj`) is always saved as UTF-8 with BOM + CRLF; a **legacy ANSI** file is converted to the same. Any conversion is NAMED in the result.
- LSP diagnostics come back in `metadata.diagnostics`; the diff in `metadata.filediffs`.

## Do NOT

- Create documentation or README files unless asked.
- Create files the task does not need — prefer changing existing ones.

## Parameters

| Parameter | Description |
|---|---|
| `filePath` | The file to write. |
| `content` | The whole file content. |

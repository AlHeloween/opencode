Writes a file to the local filesystem. Overwrites if the file already exists.

## Behavior

- **Creates parent directories** automatically — no need to `mkdir` first.
- **LSP diagnostics** run on the written file (and project) after writing. Errors are reported.
- **File formatting** respects the project's configured formatter.
- **UTF-8 BOM** preserved/detected.
- **Diff** is generated and stored for tracking/undo.
- **File events** published to the file watcher so other tools see the change immediately.

## When to Use vs Edit

- **Write**: Creating NEW files or completely replacing existing files.
- **Edit**: Modifying specific sections of existing files (prefer Edit over Write for changes to existing files — it preserves surrounding context and only modifies the target section).

## Do NOT

- Create documentation files (*.md) or README files proactively — only if explicitly requested.
- Create files unless absolutely necessary for the task. Prefer editing existing files.

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `filePath` | string | Absolute path to the file to write |
| `content` | string | The full file content |

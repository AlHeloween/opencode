**43 572 Б, 559 строк, 235 буллетов** (`sha256=935d6ef3…`).

## Четыре механизма накопления (каждый виден в тексте)

1. **Справочник внутри инструкции.** `## 0`+`## 1` ≈ **19 КБ (44 %)**: граф гейтов, лестница @INFOMARK,
   @SV_FORMAT, `@SOURCE_ROUTING` с издателями по дисциплинам, `state_contract` на 30 полей, `action_classes`.
   Нужно **по запросу**, оплачивается **каждый ход**.
2. **Метаданные дублируют тело.** `objective/identity/requires/shared_rules` + `outputs/routes` у всех 19 блоков:
   `routes` выводится из id, `identity`/`shared_rules` уже держит ACL, `outputs` повторяет имена из `state_contract`.
3. **Дубль между протоколом и гейтом.** `SEMANTIC_ATTENTION` (1 809 Б) содержит буллет 877 Б
   «Compact at a closed boundary…», который повторяет строку G9 «compact at a boundary: memory write first…».
   `INTENTION_RESET` (1 481 Б) пересказывает мандат G0.
4. **Стандарты стали абзацами.** GUI (366) + TUI (496) + Ergonomics (430) + project shape (392) + style-per-language (311)
   ≈ 2,8 КБ, а связывают лишь когда задача трогает эту поверхность. Плюс **хост-факты в продуктовом ядре**:
   Windows/cmd-квотирование, «bash unavailable», Chrome 9222, `plans/`-путь — всё это **уже есть в `AGENTS.md`**.

## Предложения (каждое — удаление или перенос, ни одного нового слоя)

| # | Что | Эффект |
|---|---|---|
| **P1** | `## 0`+`## 1` вынести в **справочник по запросу** (skill/файл). В промпте оставить: premise, порядок гейтов, терминалы, reference_grammar, и одну строку «контракт/класс источника — читай `<ref>`» | **−15 КБ (34 %)** |
| **P2** | Метаданные гейтов сжать до `objective` + правила; `identity/requires/shared_rules/outputs/routes` из рендера убрать (их держат ACL и граф) | −1,5 КБ и меньше мест для расхождения с ACL |
| **P3** | **Один владелец на правило**: протокол держит правило, гейт **ссылается** (`see @SEMANTIC_ATTENTION`). Снимает дубль 877 Б и пересказ G0 | −2 КБ |
| **P4** | Хост-факты вернуть в **host-addon** (`addons.py`, host-local) — ядро снова host-agnostic, а в `AGENTS.md` это уже написано | −1 КБ из продукта |
| **P5** | Стандарты → одна строка-указатель + справочник (GUI/TUI/ergonomics/project-shape/style) | −2 КБ |
| **P6** | **Инструмент против повторного роста**: сегодня потолок ОДИН на файл (44 000 Б), поэтому одна секция растёт, пока другие ужимаются, и это не видно. Добавить **потолки по секциям** в `test_render.py`/`test_dedup.py` | рост становится виден там, где происходит |

Итого P1–P5: **43,6 КБ → ≈22–25 КБ**, то есть ~45 % с каждого запроса; P6 не даёт накопиться снова.

## Чего НЕ предлагаю

- Резать **термины и нормы** (`## 2`, @ORACLE, DISAS, приёмку): это то, что реально меняет поведение, и их потеря оплачивается не токенами, а ошибками.
- Переносить в справочник сами **правила гейтов** — они нужны в момент исполнения гейта.
- Слепое урезание «до числа»: потолок — подсказка краткости, не гейт (правило владельца).

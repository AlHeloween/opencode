# Auth V2 / Account Service Integration Plan

## Goal

Bridge the existing Account service (`src/account/`) with the legacy Auth module (`src/auth/index.ts`) to create a unified multi-account credential management system. Add credential migration from V1 `auth.json`, environment variable injection for CI/CD, and align with upstream Auth V2 patterns.

## Abstract Definition

Three separate auth systems exist in parallel:

| System | Purpose | Maturity |
|--------|---------|----------|
| Auth module (`src/auth/index.ts`) | Provider credential storage (API keys, OAuth tokens) | Production, recently upgraded to encrypted storage |
| MCP OAuth (`src/mcp/auth.ts`, `oauth-provider.ts`) | OAuth 2.0 + PKCE for MCP servers | Production, fully tested |
| Account service (`src/account/account.ts`) | Multi-account device flow login, token refresh, org management | Production, well-tested |

The gap: Account service and Auth module are **disconnected**. A user who logs in via `Account.login()` gets a token stored in the Account repo (in-memory, SQLite-backed), but the Auth module (used by provider resolution) reads from `auth.json` separately. The two systems don't share credentials.

Additionally, there is no CI/CD-friendly credential injection mechanism — all credentials require interactive setup.

**Target**: A unified `AuthV2` service that wraps both Account and Auth, with:
1. **Unified credential resolution**: `resolveCredential(providerID)` checks Account tokens first, then Auth module, then env vars
2. **Credential migration**: V1 `auth.json` credentials auto-import into Account service
3. **Env var injection**: `OPENCODE_PROVIDER_*` env vars as credential sources
4. **Multi-account aware**: Provider resolution knows which account context it's running under

## Formalization

```
CredentialSource =
  | AccountCredential(accountID, token)   // from Account service (multi-account)
  | AuthCredential(providerID, info)      // from auth.enc (encrypted JSON)
  | PluginCredential(providerID, token)   // from plugin auth hook
  
  Note: EnvCredential removed. All credentials are file-based. See config consolidation plan
  for server.auth move to opencode.jsonc.

  resolveCredential(providerID: ProviderID, accountID?: AccountID): Effect<Credential, AuthV2Error> =
  1. if accountID specified → AccountCredential from Account.token(accountID, providerID)
  2. else → AuthCredential from auth.enc (encrypted JSON, plaintext-first fallback)
  3. else if active account has token for provider → AccountCredential
  4. else → PluginCredential from plugin auth hook
  5. else → AuthV2Error.NoCredentialFound
  
  Note: NO env var injection. Credentials are file-based (auth.enc) exclusively.
  Server auth (password/username) lives in opencode.jsonc, not in auth.enc.
```

## Structural Diagram

```
Credential Resolution Chain:

Request: resolveCredential("anthropic")
  │
  ├── 1. Account service active account token?
  │     Account.token(activeAccountID).pipe(Effect.map(t => t.forProvider("anthropic")))
  │     YES → return AccountCredential
  │     NO  ↓
  │
  ├── 3. Auth module auth.json?
  │     Auth.get("anthropic")
  │     YES → return AuthCredential + migrate to Account (async)
  │     NO  ↓
  │
  ├── 4. Plugin auth hook?
  │     Plugin.auth.authorize("anthropic")
  │     YES → return PluginCredential
  │     NO  ↓
  │
  └── 5. NoCredentialFound error
        → triggers interactive auth flow (if TTY) or reports error (if CI)

Migration path (background, non-blocking):
  AuthCredential found → Account.persistToken(activeAccountID, credential) → 
  Auth.remove(providerID) from auth.json → auth.json.enc mirrors removal
```

## Brief Implementation

### AuthV2 Service

```typescript
// packages/opencode/src/auth/auth-v2.ts

import { Effect, Layer, Context, Redacted, Option } from "effect"
import { Auth } from "./index"
import { Account } from "@/account/account"

export class AuthV2Error extends Schema.TaggedErrorClass<AuthV2Error>()("AuthV2Error", {
  message: Schema.string,
  providerID: Schema.string,
}) {}

export interface Credential {
  providerID: string
  type: "api" | "oauth" | "wellknown"
  value: Redacted.Redacted<string>
  source: "account" | "auth_enc" | "plugin"
  accountID?: string
}

export class Service extends Context.Service<Service, Interface>()("@opencode/AuthV2") {}

export interface Interface {
  resolveCredential(providerID: string, accountID?: string): Effect.Effect<Credential, AuthV2Error>
  listCredentials(accountID?: string): Effect.Effect<Credential[]>
  setCredential(providerID: string, credential: Auth.Info, accountID?: string): Effect.Effect<void>
  migrateV1Credentials(): Effect.Effect<number>  // returns count of migrated credentials
}

export const layer = Layer.effect(Service, Effect.gen(function* () {
  const auth = yield* Auth.Service
  const account = yield* Account.Service

  const resolveCredential = Effect.fn("AuthV2.resolveCredential")(function* (providerID: string, accountID?: string) {
    // 1. Account service token (if account specified or active)
    const targetAccountID = accountID ?? (yield* account.active()).id
    if (targetAccountID) {
      const token = yield* account.token(targetAccountID)
      if (Option.isSome(token)) {
        return {
          providerID,
          type: "api" as const,
          value: Redacted.make(Option.getOrThrow(token)),
          source: "account" as const,
          accountID: targetAccountID,
        }
      }
    }

    // 2. Auth module (auth.enc — encrypted JSON, plaintext-first fallback)
    const legacyCred = yield* auth.get(providerID).pipe(Effect.catch(() => Effect.none))
    if (Option.isSome(legacyCred)) {
      const cred = Option.getOrThrow(legacyCred)
      // Background migration
      if (targetAccountID) {
        yield* Effect.forkIn(
          yield* Effect.scope,
          Effect.gen(function* () {
            yield* auth.remove(providerID).pipe(Effect.catch(() => Effect.void))
            // Store in account... (implementation depends on account schema extension)
          })
        )
      }
      const key = cred.type === "api" ? cred.key : cred.type === "oauth" ? cred.access : cred.token
      return {
        providerID,
        type: cred.type,
        value: Redacted.make(key),
        source: "auth_json" as const,
      }
    }

    // 4. No credential found
    return yield* new AuthV2Error({ message: `No credential found for provider '${providerID}'`, providerID })
  })

  // ... listCredentials, setCredential, migrateV1Credentials

  return Service.of({ resolveCredential, listCredentials, setCredential, migrateV1Credentials })
}))
```

### Env Var Injection

```
Convention:
  OPENCODE_ANTHROPIC_API_KEY    → providerID="anthropic"
  OPENCODE_OPENAI_API_KEY       → providerID="openai"
  OPENCODE_GOOGLE_GEMINI_API_KEY → providerID="google-gemini"
  OPENCODE_XAI_API_KEY          → providerID="xai"
  OPENCODE_DEEPSEEK_API_KEY    → providerID="deepseek"

Priority: env vars ALWAYS win (explicit operator intent).
Security: values are Redacted — never appear in logs, never serialized.
```

### Provider Resolution Integration

In `src/provider/gateway/adaptive-client.ts` or wherever credentials are fetched:

```typescript
// OLD
const credential = yield* Auth.Service.get(providerID)

// NEW
const credential = yield* AuthV2.Service.resolveCredential(providerID)

// credential.value is Redacted<string> — must use Redacted.value(credential.value) 
// when passing to the HTTP client
headers["Authorization"] = `Bearer ${Redacted.value(credential.value)}`
```

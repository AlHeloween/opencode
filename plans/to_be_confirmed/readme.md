# Планы на подтверждение

Эта полка создана 2026-09-24 по решению владельца после сверки планов с текущим кодом. Сюда перенесены 18 файлов, которые находились непосредственно в `plans/` на момент сверки; позднее добавлен план исправления строки протокола TUI с отдельным остатком живой приёмки. Перенос **не означает выполнения, отказа от цели или подтверждения старых утверждений**. Статус каждого файла надо установить по собственным критериям приёмки и актуальному коду перед возвратом в работу.

`planstatus` читает верхний уровень `plans/` и не считает эту полку активным бэклогом. Чтобы возобновить задачу, сначала сверить её план с кодом и оракулом, убрать устаревшие пункты, назвать оставшийся критерий и вернуть актуальный план в корень `plans/`. Завершённое с доказанной приёмкой отправляется в `plans_completed/`; явно исключённое — на соответствующую отложенную полку. Не переносить файл в `plans_completed/` только из-за появления похожего кода.

Владелец отдельно подтвердил: четыре плана про Ctrl+T, automode, ChatGPT OAuth cache и выбор модели TUI **были реализованы и протестированы вживую**. Их открытые строки в файлах — долг записи, а не поручение повторить тест. Причина зависания планов по сообщению владельца: модель пыталась работать через живой `bin/` вместо изолированного окружения; это дефект кернела, а не доказательство незавершённости функций. При разборе этих четырёх планов найти уже полученные результаты, привести галки и ссылки на них в соответствие и закрыть документы; повторный прогон нужен только при новом материальном сомнении.

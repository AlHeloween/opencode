# t47 — Honest base-load analyzer: opencode, codex, claude

Owner, 2026-10-15, verbatim: «отправь робота сделать честный анализатор финальной базовой загрузки для opencode,
codex, claude. Понятно что придется шариться по гиту — но это даст нам очень много, мы прыгаем вокруг кернела не
учитывая обвязку».

**BASE LOAD** = everything a model receives on the first turn before the user's words: harness system prompt, our
kernel, instruction chain (AGENTS.md / CLAUDE.md + @imports), memory index, skills list, MCP server instructions,
tool schemas (built-in, MCP, deferred stubs), hook-injected context, environment / git-status blocks, anything else.
Per host, per component: bytes, share of total, provenance (file or code path), cache class (byte-stable prefix vs
per-session/mutable). Kernel ~66 KB; the question is what surrounds it and how much overlaps.

## Hard rules (owner, 2026-10-15 — «Только смотри никаких ключей не цеплять»)

- Every run starts in a CHILD environment with every `*_API_KEY`, `*_TOKEN`, `*_SECRET`, `*_KEY` variable REMOVED;
  record only the removed NAMES, never values. `ANTHROPIC_API_KEY` and `OPENAI_API_KEY` must be absent (with them
  set, claude/codex bill the paid API instead of the existing login).
- opencode: the layer's free keyless model from `dist\bin`; if the run needs a key, do NOT supply one — record as
  untried with why.
- claude / codex: existing login sessions as they are. Do NOT open, read, copy or parse any credential store
  (`~/.claude/.credentials*`, `~/.codex/auth.json`, keychains, `.env` files) — not even to check.
- Proxy writes the request BODY only; headers dropped before anything touches disk; list only dropped header NAMES.
- Grep capture files for `sk-`, `Bearer`, `x-api-key`, `authorization` before reporting — a hit means delete the
  capture and report the leak path.
- No key in any command line, config, brief, report or commit.
- Envelope: writes only to `experiments/2026-10-15_base-load-analyzer/`, `plans/2026-10-15_base-load-analyzer.md`,
  `plans/MASTER_PLAN.md` (generated by `svm render`) and `_progress_log.md`; read-only everything else. No `bin/`
  edits or launches, no secrets, 127.0.0.1 only. Bounds: steps 80, tools 160, loops 4, depth 2, time 5 400 000 ms.
- Commit ONLY own paths; `_progress_log.md` shared — append, keep both entries on conflict; index.lock → wait 5 s
  retry. Never `--no-verify`. When done: `pwsh -NoProfile -File _build.ps1` via cmd_runner from repo root, read its
  state.json. Report only — do NOT change any prompt, config or product code.

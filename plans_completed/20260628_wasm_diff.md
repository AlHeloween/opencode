# Sub-Plan 3: Myers Diff Engine — C→WASM

## Goal

Implement O(ND) Myers diff algorithm in C, compiled to WASM. Provides
line-level diff computation as a WebAssembly module. The TS wrapper
(`computeDiffWasm`) is available for integration into the Pierre diff
engine or any other consumer.

## Files Created

| File | Purpose |
|------|---------|
| `packages/wasm/core/src/diff.c` | Myers O(ND) diff in C, compiled to WASM |
| `packages/core/src/util/diff-wasm.ts` | TS wrapper with lazy WASM loading |
| `packages/core/test/util/diff-wasm.test.ts` | 10 test cases (correctness + perf) |
| `packages/ui/src/util/diff-wasm.ts` | UI-integrated eager loader with `diffLinesSync()` |
| `packages/ui/src/components/session-diff.ts` | **Modified** — WASM first, `@pierre/diffs` fallback |
| `packages/wasm/core/Makefile` | Updated with `diff` target |

## Implementation

### C module (`diff.c`)

```c
__attribute__((export_name("diff_compute")))
uint32_t diff_compute(
  int32_t old_ptr, int32_t old_len,
  int32_t new_ptr, int32_t new_len,
  int32_t out_ptr,  int32_t out_cap
) -> bytes written
```

Output JSON format:
```json
[
  { "type": "equal",   "oldStart": 0, "newStart": 0, "length": 5 },
  { "type": "delete",  "oldStart": 5, "oldEnd": 6 },
  { "type": "insert",  "newStart": 5, "newEnd": 7 },
  { "type": "equal",   "oldStart": 6, "newStart": 7, "length": 3 }
]
```

### TypeScript wrapper (`diff-wasm.ts`)

```typescript
export interface DiffHunk { ... }
export async function computeDiffWasm(oldText: string, newText: string): Promise<DiffHunk[] | null>
```

Returns `null` if WASM is unavailable — caller falls back to TS diff.

### Integration Note

The `@pierre/diffs` package (`parseDiffFromFile`) is a synchronous external
npm module. Full integration (replacing `parseDiffFromFile` with WASM) requires
an async call chain change in `packages/ui/src/components/session-diff.ts`.
The WASM module and wrapper are ready for integration when that architectural
change is made.
